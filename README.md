# 🍳 Cooking AI - Your Personal Chef Assistant

Cooking AI is an intelligent chef assistant that creates personalized recipes based on your budget, dietary preferences, and skill level. Just tell it what you want to cook, your budget, and any dietary restrictions - and it will give you the best recipe!

## ✨ Features

✅ **Budget-Friendly Recipes** - Get recipes within your budget
✅ **Easy-to-Follow Instructions** - Steps explained in simple language
✅ **Dietary Support** - Vegetarian, vegan, gluten-free, and more
✅ **Ingredient Explanations** - Learn what each ingredient does
✅ **Cooking Tips** - Pro tips to make your cooking better

## 🚀 How to Use

### Installation

```bash
git clone https://github.com/adilthebestgamer10-glitch/Cooking-Ai.git
cd Cooking-Ai
pip install -r requirements.txt
```

### Setup Your API Key

1. Get a free API key from [Google Gemini](https://aistudio.google.com/apikey)
2. Create a `.env` file in the root folder:

```
GEMINI_API_KEY=your_api_key_here
```

### Run the Application

```bash
python cooking_ai.py
```
